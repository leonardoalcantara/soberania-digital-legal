# Part 2—User empowerment tools

# ^5 Minimum standards for user empowerment tools

User empowerment tools must be designed, offered and managed in accordance with the following standards:

(a) users must be made aware of user empowerment tools in an obvious and straightforward manner;  
(b) user empowerment tools must be:

(i) accessible; and

(ii) easy to use; and

(iii) prominently available on the service; and

(iv) functional; and

(v) available on an ongoing basis;

user empowerment tools must use clear and simple language;

(d) user empowerment tools must allow users to control design features of the service in a way that supports a positive, safe and healthy experience;  
(e) user empowerment tools must not make the service harder to use or navigate, or affect the broader functionality of the service;  
(f) alternative feed options such as following-only feeds must not make the service harder to use or navigate;  
(g) use of user empowerment tools must not be discouraged, whether explicitly or implicitly;  
(h) users of user empowerment tools must be provided with a similar experience to users who have not enabled those tools;  
(i) a user's settings for user empowerment tools must not change, either during a single use of the service or when the service is used from time to time, without the user making an explicit choice to change those settings.

# ^6 Choice of preferred feed

(1) A social media or an age-restricted social media platform that offers users of the service user-generated content through a recommender feature must provide a user empowerment tool that allows users to determine their preferred feed.  
(2) A preferred feed is the feed through which a user receives material:

(a) chosen by algorithms based on user profiling; or  
(b) from accounts the user follows.

(3) A user follows an account if the user subscribes to, or connects with, the account in order to automatically receive content from the account.  
(4) One of the options for the preferred feed must be a following-only feed.  
(5) A following-only feed is a feed that does not include material other than material from accounts the user chooses to follow.

(6) A following-only feed may include advertising material, including advertising material from an account the user does not follow.

Note: A following-only feed must not make the service, or the feed, harder to use or navigate: see paragraphs 5(1)(e) and (f).

# ^7 Initial prompt for preferred feed

(1) This section applies if, on the commencement of this section, a user of a social media service or an age-restricted social media platform has not chosen their preferred feed.  
(2) When the user next accesses the service in a logged in state, the user must receive a prompt for the user to choose their preferred feed.

Note: Settings for user empowerment tools must not change without the user explicitly choosing to change those settings: see paragraph 5(1)(i).
